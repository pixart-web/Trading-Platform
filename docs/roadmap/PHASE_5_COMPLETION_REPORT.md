## Financial coverage, security, migration risks and debt

All fixtures are synthetic and test-only. Prefix invariance, causal confirmation, late imports,
fixed Decimal geometry, lifetime evidence, expiry/eviction and quality failures are covered.
Code coverage is not economic validation. No forecasts, calibrated probabilities, profitability,
costs, fills or recommendations are fabricated. Strength is a heuristic, not trading readiness.

No secret, provider credential, broker connection, order or withdrawal capability was added.
Live execution remains disabled and cannot be enabled by this foundation. Database failures
return not-ready errors. Existing proxy restrictions remain; zones adds only a bounded GET path.
No schema migration or data rollback required; additive API and opt-in UI preserve existing clients.

Debt: real provider/import operations, session calendars, persisted/incremental analytics, empirical
strength calibration, costs/liquidity/drawdown/ruin evaluation, public authentication/rate limits,
broader observability and upstream deprecation warnings. Current-role bands are latest-state
visualization, not historical backtests. Query-window warm-up affects results; lifetime counters
survive flips. No out-of-sample or economic test has been performed on real market data.

Next phase: 6 — multi-timeframe analysis, aggregation and disagreement. Not started.
