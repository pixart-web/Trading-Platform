## Skip audit

The 231 local skips are generated by the `repository` fixture's SQLite/PostgreSQL parameterization when `PA_INTEGRATION != 1`, plus the PostgreSQL-only numeric-constraint branch on SQLite and the explicit integration test. They are environment-specific, not counted as passes. GitHub CI sets `PA_INTEGRATION=1`, uses real PostgreSQL and Redis, and reports 1299 passed with one intentional SQLite half of a PostgreSQL-only numeric-constraint assertion skipped.
