# Production readiness

| Gate | State | Evidence / blocker |
|---|---|---|
| UI_READY | YES | Reference-derived shell, responsive workflows, visual capture/diff, E2E |
| APPLICATION_PRODUCTION_READY | YES_WITH_LIMITATIONS | RESEARCH/PAPER scope, proxy authentication, internal services, prior audit |
| HETZNER_DEPLOYMENT_PACKAGE_READY | YES | Compose, Caddy, environment template, preflight/deploy/backup/restore and runbooks |
| LIVE_SPOT_ENGINEERING_READY | NO | No selected venue, write adapter conformance, credentials or live qualification |
| LIVE_SPOT_ACTIVATION_AUTHORIZED | NO | Explicitly outside this task |
| LIVE_DERIVATIVES_READY | NO | No venue-specific native implementation/qualification |
| AUTOPILOT_LIVE_READY | NO | No qualified live execution or approved operator controls/drills |
| ECONOMIC_EDGE_VALIDATED | NO | No protected real-data OOS/walk-forward/shadow evidence |

Manual deployment prerequisites are DNS/host, secrets, firewall, monitoring/alerts, encrypted off-server backup and an approved window. Basic Auth is restricted to a private single-operator installation. Fundamentals/context/derivative intelligence have backend GET contracts but are not yet first-class interactive widgets. Metrics/tracing, SSO/MFA and immutable multi-platform image digests remain debt.

No real-money activation should be offered until all relevant qualification reports are independently changed to YES with concrete venue, account, risk, operational and economic evidence.
