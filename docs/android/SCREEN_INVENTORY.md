# Android screen inventory

| Destination | Native behavior | Remaining acceptance gap |
|---|---|---|
| Login | Configurable HTTPS origin, operator/password login, revocable encrypted session | Biometric local unlock and provisioning UX are absent |
| Dashboard | Registered-market search/paging, bounded candles/volume, score, directional/forecast evidence, historical snapshot selection | Desktop-equivalent ticker, opportunity/portfolio summary composition and overlays incomplete |
| Analyze / Intelligence / Forecasts | Existing immutable report, all 13 horizons, evidence/version/coverage and explicit unavailable state | Independent technical/structure/regime kernels lack complete native read models |
| Full chart | Candles/volume, timeframe, pinch/pan, crosshair, price/date/OHLC labels and older window loading | Server indicators, zones, structure and target overlays incomplete |
| Watchlists | Create, rename, archive/delete, add/remove market, revision conflicts, latest snapshot, cached reads | Sorting/filtering, alert presentation and offline draft synchronization incomplete |
| Scanner | Server scan, universe, direction, horizon, score/liquidity/uncertainty filters, groups/exclusions, history | Complete filter UX and durable draft/retry workflow incomplete |
| Portfolio | Separate manual portfolios, server valuation/positions/ledger/intelligence, create and step-up accounting form | Full history paging, chart presentation and all financial failure/device scenarios incomplete |
| Fundamentals | Stored fact snapshot with reporting/publication/availability/revision provenance | Rich ratios/context layout and provider-qualified evidence incomplete |
| Derivatives | Contracts, term structure, option skew and contract context | Real-provider coverage/qualification incomplete |
| News / Sentiment / Macro | Causal stored context lookup and full source fields | Feed discovery/selection and provider configuration incomplete |
| Backtesting | Known-run report retrieval | No durable authenticated submission/job API exists |
| Research / Reports | Known report/model inspection | No job scheduler/status/catalog API exists |
| Strategies | Existing catalog and lifecycle evidence | Lifecycle mutation stays operator/backend-only |
| Paper Trading | Actual server account/config/state, orders/fills/fees/reconciliation fields | No native account start/control API; comprehensive PAPER UI/device validation incomplete |
| Risk / Execution / Autopilot | Explicit safe-boundary/capability status | No safe operational monitoring contract; internal journals are not exposed |
| Settings | Server identity, device inventory/revocation, logout, notification permission | Synchronized UI preferences and remote device push registration incomplete |
| System Health | Authenticated native capability response | Full provider/risk/dependency health stream incomplete |

All listed routes are reachable through native navigation. Reachability is not proof of feature parity. Generic expandable evidence views retain server fields rather than replacing unavailable capabilities with invented values.
